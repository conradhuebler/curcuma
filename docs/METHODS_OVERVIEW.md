# Methods overview

Every energy method of curcuma (`-method <name>`), what it is, and which parameters it reads.
The table below is a summary; the source is the method catalog in
`src/core/energy_calculators/method_catalog.cpp`, printed by `curcuma -help methods` (all names) and
`curcuma -help <method>` (one method with its parameters). Status: all native methods are AI-generated
and machine-tested; none is TESTED or APPROVED by the operator.

## Shared SCF knobs (knob x method)

Flat flags of module `scf` (`scf_parameters.h`); `-scf_guess`, `-scf_extrapolation` are the method scope's own
(`-xtb.*` or `-qm.*`), routed by `-method`. "not supported" and "n/a" give a warning at run time
("not read by method ..."); "no effect" = read, but an unconverged SCF stays an error. Defaults in the cells.

## Design

Operator decision of 2026-10-31: help, parameter routing and documentation are organised per METHOD (gfn2, gfnff,
b2plyp, hf-3c, uff), not per implementation family (no `qm`/`sqm` help category).

- One source: `kMethodCatalog` in `method_catalog.cpp` declares every MethodFactory name (implementation, status,
  gradient, GPU, restrictions, parameter groups, routing scope). `-help <method>`, `-help methods`, the unread-parameter
  warning and the flat-flag routing (`MethodFactory::parameterScopeForMethod`, `readsSharedScfScope`) read it.
- Warning, not error: an unregistered `-<module>.<name>` or a parameter the selected method does not read is reported
  (only with an explicit `-method`/`-*_method`; silent at `-verbosity 0`); the run continues.
- Every new method and every new parameter of a method module must be declared in the catalog, so it is reachable through
  `-help <method>` and its flat name; `curcuma -check_method_catalog` (ctest `method_catalog_consistency`) fails otherwise.
- `-help <name>` resolves category, then capability, then method; collision `orca` (capability and method):
  `-help method:orca` shows the method.

## Not covered

- Parameters set through `-import_config` JSON are not checked for being read (only the command line).
- Unregistered legacy flags in the command module are not judged (no warning).
- `-help <method>` shows the first sentence of each help text; the full text is in `curcuma -help_module <module>`.
- The flat-name column assumes the active command does not register the same name (`-max_iterations` at `-sp` stays with the optimiser).
