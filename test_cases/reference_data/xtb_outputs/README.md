# xtb outputs

Output files of xtb 6.6.1 (`xtb <structure>.xyz --gfnff ...`, program call in each file) for the structures of the same name. They are single-point
reference calculations at the geometry of the library structure and are listed under `reference_calculations` in
`test_cases/structures/manifest.json`; they do not document how the geometry was optimised. Moved here from `test_cases/molecules/` on 2026-10-01.
