# Delta-ML campaign scripts (scripts/deltaml_usecase*)

These are the measurement scripts of the AI-run Delta-ML campaigns of Oct 2026, kept as a record of how the numbers
in the linked documents were produced. They are not maintained tools: paths are hard-coded, nothing was generalised.
Status: AI-generated, not human-reviewed; all of it was run on one machine.

Reading notes, all from the code:

- Every script hard-codes `/home/conrad/src/curcuma/build_deltaml/usecase<N>/` (variable `UC`, `UC4`..`UC6`, `U`, `U8`,
  `U9`, `U10`, or a literal `cd`) and the binary `curcuma_uc<N>` in it (`curcuma_uc` for the first directory). The
  scripts are not run from `scripts/`; the Python files put `build_deltaml/usecase<N>/scripts` on `sys.path`, so they
  must be copied to that folder first (all of those folders exist locally).
- Shared modules: `common.py`, `common2.py`, `common3.py` (extended by `common4.py`, `common5.py`, which also set
  `common3.BIN`), `common6.py`, `common7.py` (also imported by usecase8, 9, 10). Usecase9/10 shell scripts are
  derived from usecase8 ones.
- `xargs -P n -L 1` is the only parallel driver; `.flag` files and `STATUS.txt` mark completion.
- "not recoverable" below means: no script in the directory calls the others and no file dependency fixes the order.
